# Развёртывание

Домен: **culc-bot.cu3rd.ru**. TLS терминирует Caddy на хосте, сертификат
Let's Encrypt выпущен и действует до 8 декабря 2026, `http://` отдаёт 308 на
`https://`. Caddy проксирует на `127.0.0.1:8090`, туда же публикует порт
контейнер `api`.

```
culc-bot.cu3rd.ru ──TLS──> Caddy ──> 127.0.0.1:8090 ──> контейнер api :8000
```

`X-Forwarded-For` и `X-Real-IP` Caddy проставляет сам, WebSocket проксирует из
коробки — приложению дописывать ничего не нужно. Uvicorn запускается с
`--proxy-headers --forwarded-allow-ips '*'`, потому что видит только Caddy.

## Порт публикуем только на localhost

В `docker-compose.prod.yml` стоит `"127.0.0.1:8090:8000"`, и это не украшение.
Без явного адреса Docker публикует порт на всех интерфейсах и правит iptables
в обход ufw: приложение оказалось бы доступно снаружи по голому http, мимо
Caddy и мимо TLS. Так же сделаны все остальные сервисы на этом хосте.

Занятые порты хоста — не пересекаться: 8000, 8089 (cinema), 8090 (мы),
8100–8102, 8201, 5432, 2019 (admin API Caddy). Если понадобится второй порт —
свободен 8091.

## Секреты

`.env` в образ не попадает: он перечислен в `.dockerignore`, а в контейнер
значения приходят через `env_file`. Каталог, который приложение отдаёт наружу
как статику, — только `/app/frontend`, и в нём лежит исключительно результат
сборки Vite.

Это не теория: через пару минут после появления домена в CT-логах на него
пришёл сканер (104.244.74.39) и перебирал `/.env`, `/.env.prod`, `/.env.local`.
Тогда отвечал 502, ничего не утекло. После запуска эти пути отдаст SPA-фолбэк
из `app/main.py` — он умеет отдавать только файлы внутри `FRONTEND_DIR` и
проверяет, что вычисленный путь лежит внутри него, так что выйти за пределы
каталога запросом нельзя.

Проверить после первого запуска:

```bash
curl -s -o /dev/null -w '%{http_code}\n' https://culc-bot.cu3rd.ru/.env
```

Ожидаемо — 200 с содержимым `index.html` (SPA-фолбэк), но никогда с
содержимым `.env`. Если однажды увидите там переменные окружения — значит
`.env` попал внутрь `FRONTEND_DIR`, и это авария.

## Первый запуск

```bash
cp .env.example .env   # заполнить TELEGRAM_BOT_TOKEN, SECRET_KEY, POSTGRES_PASSWORD
docker compose -f docker-compose.prod.yml up -d --build
```

`MINIAPP_URL=https://culc-bot.cu3rd.ru` — этот адрес бот ставит кнопкой меню,
и по нему же Telegram открывает Mini App.

Бэкап конфига Caddy на хосте: `/etc/caddy/Caddyfile.bak.2026-09-09-150235`.
